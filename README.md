# Amanda Cascales · Unity Game Developer

Game developer with a background in multimedia engineering and an MSc in Video Game Design and Programming. I work with Unity and C#, focusing on game systems architecture: modular, maintainable code that's easy to extend.

This repository collects my projects, prototypes and technical write-ups.

## Featured Projects

### Relics · Team project, custom engine
Third-person shooter with platforming elements set in a low-poly magical world. Built from scratch in 9 months by a team of four using only raylib, with no off-the-shelf engine. **My role:** designed and implemented the game's ECS (Entity Component System).
[Play on itch.io](https://infinite-magic.itch.io/relics)

### Stomagochi Kids · Serious game, final degree project (graded 10/10)
Android game made with Godot to help children with ostomies with their integration and learning about their treatment. Features avatar customization (including the stoma and ostomy bag) and a minigame where the child trims the ostomy disc to fit their stoma, reinforcing the right habit in real life. Developed in collaboration with the University of Alicante and the ostomy nursing department at Hospital Vall d'Hebron.
[Download on itch.io](https://mandicv.itch.io/stomagochi-kids)
